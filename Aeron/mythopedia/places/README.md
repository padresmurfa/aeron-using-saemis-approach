# Places

This directory contains canonical entries for named locations of mythic significance on Aeron.

## Current Entries

- `eden.md` — the hidden garden where the four [Firsts](../entities/firsts.md) dwell, real but unreachable to mortals.

## Forthcoming

Continent canon, named major cities, dwelling-sites of the [Vorothar](../legendary_beasts/README.md) (gated to follow continent canon), sacred sites of pantheon worship, and other place-of-significance canon will be tracked here as the corpus develops.
