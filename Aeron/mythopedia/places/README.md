# Places

This directory contains canonical entries for named locations of mythic significance on Aeron.

## Continent Canon

Aeron has **seven canonical continents** ([Athralin](../../primal_language/structural_principles/athralin.md)). The continent spine is at `continents.md`; per-continent entries follow:

- `continents.md` — the seven-continent spine
- `athralorn.md` — The Heartland (central, multi-kingdom; hosts `Drathalon`, `Aelvorath`)
- `kethrarvel.md` — The Frostbound North (cold, fortified; hosts `Skaelmorath`, `Velkoraen`)
- `miravarath.md` — The Burning South (desert, volcanic; hosts `Vorthalen`, `Khoramor`)
- `phaeravar.md` — The Eastern Ancient (deeply-historied; hosts `Vothorisk`, `Phaelvenor`)
- `seralinor.md` — The Sea-Threading (archipelago; hosts `Drovenrath`, `Krevoraen`)
- `tavorath.md` — The High Crown (high-altitude, sky-temple; hosts `Mirathven`, `Vesselrath`)
- `oraevenel.md` — The Lost Verge (small, liminal; **the continent IS `Athravenel`'s dormant body**; also hosts `Khaethorom`)

## Other Canonical Places

- `eden.md` — the hidden garden where the four [Firsts](../entities/firsts.md) dwell, real but unreachable to mortals.
