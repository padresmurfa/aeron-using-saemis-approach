# Mechanics

This directory contains canonical entries for cosmic mechanics — recurring ritual-form, mage-craft pattern, or cosmological-process canon that is structural rather than tied to any specific entity, era, or place.

## Current Entries

- `hero_summoning.md` — hero-summoning, reincarnation, and prophecy. The mechanism by which fated beings are identified through their Class 2 fated-being star, summoned through ritual targeting, reincarnated across worlds, and prophesied before they are born. Rests on the [Star-Fate Doctrine (R2 + positional-weighting)](../astrology/star_fate.md).
