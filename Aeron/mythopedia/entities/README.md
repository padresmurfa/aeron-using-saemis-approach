# Entities

This directory contains canonical entries for beings and named intelligences in Aeron.

## Current Entries

- `aru.md` — `Aru`, the Creator before [Orun](../events/first_pulse.md) (the First Pulse).
- `loran.md` — `Loran`, the Creator after Orun, in dynamic harmonic state. **Loran is the same singular being as Aru, not a second tier-1 entity.** See [Divine Oscillation](../cosmology/divine_oscillation.md).
- `firsts.md` — the four directly Creator-created mortal-tier beings: humanic Adam, humanic Eve, demonic Adam, demonic Eve. They dwell in [Eden](../places/eden.md). See [Light/Darklight Affinity](../cosmology/light_darklight_affinity.md) for the racial-affinity inheritance through which they anchor mortal mana.

## Conventions

All entity files must use canonical primal-language headwords, with English glosses used only as gloss. After first introduction, prefer the primal name alone or `PrimalWord (English gloss)` rather than the English gloss by itself.

## Forthcoming

The pantheon-leader gods of the [five canonical pantheons](../cosmology/pantheons.md) and the fourteen [Vorothar (Cataclysmic Beasts)](../legendary_beasts/README.md) are entities in the broader sense but live in their own dedicated directories. Future named entities below tier-1 — pantheon-leaders, Vatharen, demi-gods, and other named beings — may be tracked here as the corpus develops.
